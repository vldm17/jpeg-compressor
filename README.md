# ⚡ JPEG Compressor & Artifact Studio 2.0

Профессиональная студия для глубокого сжатия изображений в формате **JPEG с регулируемой потерей качества**, симуляции легендарных **JPEG-артефактов** ("шакализация", поколенческие потери / generation loss, VHS-глитч, Deep-Fried мемы) и точного научного анализа искажений (**PSNR** и **тепловая карта потерь**).

Программа доступна в двух синхронизированных форматах:
1. **Нативное настольное приложение для Windows** (`run.bat` или `py app.py`) — с многопоточным пакетным сжатием на всех ядрах CPU, экранной 4x лупой, анализом EXIF и вкладками настроек.
2. **Автономная веб-версия 2.0** (`open_web.bat` или `web_app/index.html`) — работает прямо в любом браузере (Edge / Chrome) в 1 клик без зависимостей.

## 🌟 Что было улучшено во 2-й версии (х2 Улучшение)

### 1. Интеллектуальный режим целевого размера (Target Size Mode)
* Больше не нужно гадать со слайдером качества: введите желаемый размер в КБ (например, **200 КБ**, **256 КБ для Discord**, **500 КБ для Telegram**), и алгоритм бинарного поиска подберет оптимальный коэффициент качества за миллисекунды.

### 2. Научный анализ качества (PSNR & Метрики искажений)
* **PSNR (Peak Signal-to-Noise Ratio в dB)**: математический расчет уровня шума и деградации сигнала.
  * `> 36 dB` — высочайшее качество, искажения незаметны для глаза.
  * `30–36 dB` — веб-стандарт, оптимальный баланс сжатия и четкости.
  * `22–30 dB` — заметные 8×8 блоки и звон на контрастных краях.
  * `< 20 dB` — экстремальное разрушение (шакал).
* **Суммарная среднеквадратичная ошибка (RMSE)**.

### 3. Тепловая карта потерь (Difference Heatmap)
* Специальный режим отображения, рассчитывающий матрицу поэлементной разности $|Оригинал - Сжатое|$.
* Использует цветовую палитру **Turbo**:
  * **Черный / Синий** — пиксели сохранены без изменений.
  * **Зеленый / Желтый** — умеренные потери высокочастотных деталей.
  * **Красный / Белый** — максимальные искажения и потеря информации.

### 4. Интерактивная экранная лупа 4× (Magnifier Loupe)
* Нажмите кнопку **🔍 Лупа 4x** — круглая плавающая линза будет следовать за курсором, увеличивая микроструктуру картинки в 4 раза алгоритмом Nearest Neighbor, позволяя вблизи рассматривать структуру 8×8 блоков квантования DCT.

### 5. Стилизация и глитч-эффекты
* **Хроматическая аберрация (сдвиг R/B каналов 0–10 px)**: аналоговый сдвиг цвета, создающий эффект VHS, старых линз и ретро-камер.
* **Deep-Fried Насыщенность (1.0x – 3.0x)** и **Контраст артефактов (1.0x – 2.5x)**: культовый эффект жареных мемов, при котором JPEG-блоки взрываются яркими цветовыми пятнами.
* **Сдвиг сетки DCT**: циклический сдвиг фазы блоков при многопроходном сжатии (Generation Loss).

### 6. Управление просмотром
* **↔ Вертикальный сплит** и **↕ Горизонтальный сплит**: выбирайте удобное направление разделителя.
* **Мгновенное сравнение по [ПРОБЕЛУ]**: зажмите клавишу Пробел в любой момент, чтобы увидеть оригинальное изображение; отпустите — вернется сжатый результат.
* **Зум колесиком мыши** и **панорамирование правой кнопкой мыши (ПКМ)**.

### 7. Многопоточный пакетный экспорт (Multi-core Batch 2.0)
* Пакетное сжатие теперь задействует все доступные ядра процессора через пул потоков `ThreadPoolExecutor`.
* Поддержка экспорта в:
  * **JPEG (`.jpg`)** — классическое сжатие.
  * **PNG (`.png`)** — сохранение точных JPEG-артефактов без повторного пережатия (lossless freeze).
  * **WebP (`.webp`)** — современный формат для веб-разработки.
* Очистка EXIF-метаданных (геолокация, модель камеры, дата съемки) для конфиденциальности и дополнительной экономии размера.
